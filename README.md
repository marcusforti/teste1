# 💡 Ideias

Espaço para guardar ideias capturadas pelo Claude Code no app do celular.

## Como usar

Abra uma sessão do Claude Code neste repositório e mande a ideia do jeito que vier:
texto solto, áudio transcrito, lista, rascunho. O Claude organiza e salva em `ideias/`.

Exemplos de pedidos:

- "Anota uma ideia: app que lembra de regar as plantas pela previsão do tempo"
- "Lista minhas ideias"
- "Desenvolve mais a ideia do app de plantas"
- "Junta as ideias parecidas"

## Estrutura

```
ideias/
  AAAA-MM-DD-nome-curto.md   ← uma ideia por arquivo
```
