# Agentes de roteiro

Prompts de sistema para colar no ChatGPT (GPT personalizado ou Projeto) ou no Claude (Projeto →
instruções). Use na ordem:

1. **[estrategista.md](estrategista.md):** produto e público → ângulos de venda
2. **[roteirista-ugc.md](roteirista-ugc.md):** um ângulo → roteiros de 15 a 40 s prontos para o campo "Roteiro" do `/clone`
3. **[diretor-de-cenas.md](diretor-de-cenas.md):** roteiro → descrições de cena para o campo "Cena" e prompts de b-roll para o Workspace
