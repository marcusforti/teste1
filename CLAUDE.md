# Instruções para o Claude

Este repositório é um caderno de ideias, usado principalmente pelo celular.
Responda sempre em português, de forma curta (a tela é pequena).

## Ao receber uma ideia nova

1. Crie `ideias/AAAA-MM-DD-nome-curto.md` (data de hoje, nome em kebab-case, sem acentos).
2. Use o modelo abaixo. Preserve a ideia original com as palavras do usuário;
   não invente detalhes — o que for sugestão sua vai em "Próximos passos".
3. Faça commit e push direto na branch atual, sem pedir confirmação.
4. Responda em uma ou duas linhas confirmando o que foi salvo.

```markdown
# Título da ideia

**Data:** AAAA-MM-DD
**Tags:** #tag1 #tag2

## A ideia
(texto original do usuário, só com limpeza de digitação)

## Próximos passos
- ...
```

## Outros pedidos comuns

- **Listar ideias:** mostre título + data + tags, mais recentes primeiro.
- **Desenvolver uma ideia:** acrescente seções no mesmo arquivo; não sobrescreva "A ideia".
- **Ideia parecida com uma existente:** avise e pergunte se é para juntar.
